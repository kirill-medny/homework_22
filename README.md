### Домашняя работа №28 Права доступа

Из-за наплыва пользователей стало появляться много продуктов, которые администратор не успевает обрабатывать. 
Поэтому возникла необходимость проводить ручное модерирование продуктов, которые добавляются на платформу. 
Для этих целей было решено нанять модераторов.

Задание 1
Создана группа для роли «Модератор продуктов» и настроены необходимые разрешения.

Добавлены кастомные права к модели продукта.
can_unpublish_product — может отменять публикацию продукта

Создана группа «Модератор продуктов» с правами:
Разрешение can_unpublish_product.
Разрешение на удаление любого продукта.

Задание 2
Реализвано решение, которое проверяет, что редактирование и удаление продукта доступно только его владельцу.

Добавлено поле владельца (owner) к модели продукта.
Поле должно связано с моделью пользователя через ForeignKey.

При создании автоматически привязывается продукт к авторизованному пользователю.
При создании нового продукта поле owner должно автоматически заполняется текущим авторизованным пользователем.

Настроена проверка в контроллерах, чтобы только владелец мог редактировать и удалять продукт.
Реализована проверку прав доступа в представлениях для редактирования и удаления продуктов, 
чтобы только владелец мог выполнять эти действия.

* Дополнительное задание
